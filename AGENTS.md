# Public catalog conventions

- Review the working tree and current branch before editing. Integrate changes into `main` through a reviewed pull request.
- Verify the manufacturer, exact model, applicable variant, and source before adding device metadata. Share only data and assets cleared for public distribution.
- Use GitHub Issues for model requests, corrections, and public source links. Keep full Thing Models, private files, and credentials outside this repository.
- Use lowercase kebab-case filenames except where an external tool requires a different name.
